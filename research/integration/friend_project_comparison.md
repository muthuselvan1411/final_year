## Integration decision

The compatible integration boundary is:

`normalized event -> event-window features -> detector contract -> evidence -> advisory policy -> incident JSONL`

When no validated event-window detector is configured, the pipeline emits an
explicit `ABSTAIN`. It never turns missing model output into a benign result and
never performs process termination, quarantine, or other containment.
